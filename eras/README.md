# Reconstructed historical eras

`eras/` contains the project's current best runnable models of historically
plausible system states. These are capability-oriented analytical slices in a
continuous transition; they need not be boundaries Bell Labs participants
named or recognized.

Historical eras are living reconstructions. Better evidence may correct their
contents, with the reason and provenance recorded. Git and `snapshots/`
preserve earlier project interpretations and milestone evidence.

- [`pdp7-unix/ERA.md`](pdp7-unix/ERA.md) — usable late PDP-7 Unix baseline.
- [`pdp7-crossdev/ERA.md`](pdp7-crossdev/ERA.md) — PDP-7 Unix carrying the
  reconstructed PDP-11 cross-assembler and paper-tape producer.
- [`pdp11-crossdev/ERA.md`](pdp11-crossdev/ERA.md) — diskless PDP-11/20
  receiving PDP-7-produced programs through paper tape.

See [`../docs/RUNNING.md`](../docs/RUNNING.md) for the short guided journey.
