# Reconstructed historical eras

`eras/` contains the project's current best runnable models of historically
plausible system states. These are capability-oriented analytical slices in a
continuous transition; they need not be boundaries Bell Labs participants
named or recognized.

Historical eras are living reconstructions. Better evidence may correct their
contents, with the reason and provenance recorded. Git and `snapshots/`
preserve earlier project interpretations and milestone evidence.

- [A working Unix](pdp7-unix/ERA.md) — log into the PDP-7 and explore files.
- [Write for the new machine](pdp7-crossdev/ERA.md) — a PDP-11 assembler is
  now available on PDP-7; use it to produce target words and punch that exact
  result for the receiving machine.
- [Bring the tape across](pdp11-crossdev/ERA.md) — the diskless PDP-11/20
  reads a PDP-7-produced program through its loader and answers your keyboard.

These three names remain useful machine/capability labels. Assembly and
punching need not become separate directories to be distinct discoveries.
A new public state must offer a meaningful new human capability, not simply
mark another engineering checklist complete.

See [`../docs/RUNNING.md`](../docs/RUNNING.md) for the short guided journey.
