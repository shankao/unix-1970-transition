# Generated Artifacts

Generated paper-tape images, listings, dumps, and emulator captures may be kept here when useful.

Artifacts are not authoritative unless reproducible from checked-in source and documented tools. Large or frequently regenerated files may later move to releases rather than Git history.

`kl11-poll.simh` is regenerated by `python3 tools/run_kl11_poll.py --record`
from the native PDP-7 `as11` trace. Run it manually from the repository root:

```sh
pdp11 artifacts/kl11-poll.simh
```

After the readiness message, type two characters; each is echoed through the
polled KL11, then the PDP-11 halts.
