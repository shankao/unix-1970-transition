# Stage 3A execution evidence

Everything in this directory is class **M** modern instrumentation/evidence.
`manifest.txt` and `test-?.simh` are deterministically generated by
`tools/build_stage3a.py`; the scripts explicitly deposit words and start the
class-B nucleus at `001000`. `test-?.transcript.txt` are canonical fresh-log
SIMH runs. `test-a-initial-failure.transcript.txt` preserves the first A run,
which halted before queued console output became visible.
