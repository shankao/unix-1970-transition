# Stage 3B execution evidence

This directory is class **M** instrumentation/evidence. `manifest.txt` and the
nine `test-?.simh` explicit-deposit scripts are generated by
`tools/build_stage3b.py`; canonical transcripts use fresh SIMH logs.
`test-g-initial-failure.transcript.txt` preserves the first loop run, which
revealed that the initial reconstructed `b4` clobbered CMP flags with CLR.

Canonical results are E=`E`, F=`F`, G=`123`, H=`H` (synthetic `n11`), I=`A`
(one argument), J=`B` (two arguments), K=`C` (value return), L=`D` (nested
frames), and M=`V` (void return). All HALT at PC `001302` and record the bare
24 KB, KE-disabled, disk/tape-disabled configuration.
