# PDP-11 cross-development era

This is the first preserved PDP-11 era: a bare PDP-11/20 KA11 with 24 KB
running a representative program whose exact words were generated by native
PDP-7-hosted `as11`. The host parsed and deposited those words but did not
encode or replace them. Development therefore targets and runs on the PDP-11
while its assembler remains hosted on the PDP-7: this is cross-development,
not PDP-11 self-hosting.

From this directory run:

```sh
pdp11 kl11-poll.simh
```

The preserved diagnostic polls KL11 receiver and transmitter registers. Type
any two ordinary characters; each is echoed and the processor then halts. For
example:

```text
KL11-POLL READY - TYPE 2 CHARACTERS
ki
HALT instruction, PC: 001076 (HALT)
```

The era has no interrupt handling, low-core vector/RTI framework, TRAP or
system calls, UNIX kernel, filesystem, or RF11/RS11 storage. `pdp11.simh` is an
era-local clean machine configuration and `kl11-poll.simh` depends only on it.
